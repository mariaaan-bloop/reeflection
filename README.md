# Reeflection 

**Reeflection** adalah konsep bisnis digital berbasis gamifikasi yang bertujuan mendukung konservasi terumbu karang sekaligus memperkuat partisipasi masyarakat dalam ekonomi biru.

## Project Overview

Project ini dikembangkan sebagai bagian dari **Business Plan Competition**, mencakup analisis masalah, validasi pasar, business model, konsep produk, prototype, dan analisis finansial.

## Key Highlights

* **Market Validation:** 68% responden tertarik dengan layanan adopsi karang digital.
* **Business Model:** Virtual coral adoption, digital certificate, gamification, dan partnership konservasi.
* **Product Strategy:** Monitoring karang, community impact, levels, badges, dan leaderboard.
* **Financial Analysis:** Proyeksi revenue Rp166 juta dan net profit Rp60,65 juta.
